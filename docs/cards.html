Technical architecture

The model exists twice.
A test proves they agree.

Instant local feedback needs the model in the browser. A trustworthy server needs it on the backend. Two implementations normally drift, so we made drift impossible.

Client

engine/impact.ts

TypeScript. Runs on every slider drag. No network round trip, no latency.

parity.test.ts
Server

server/engine.js

JavaScript. Authoritative for anything persisted or shared between users.

The harness drives both engines with the baseline allocation, twelve randomized allocations, and every service swept across its full funding range. If they ever disagree, the build fails.
